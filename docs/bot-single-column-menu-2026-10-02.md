# Меню Work&PlayVPN: одна кнопка на строку

База: 3e6db76. Обновлены только клавиатуры бота и экран помощи. Миграций и изменений env нет.

- Общий рендерер клавиатур размещает по одной кнопке на строку в главном меню, подписках, устройствах, регионах, тарифах, оплате и документах.
- Синие акценты: открытие Mini App/инструкций, ключ и QR-код, копирование ссылки, выбор каталога, смена региона, переход к оплате. Назад и второстепенные действия сохраняют обычный стиль.
- Отключение устройства и его подтверждение выделены красным. Подтверждение отключения сохранено.
- В главном меню названия «Мои подписки» и «Каталог подписок». В подписке уточнены названия действий и добавлена существующая команда смены региона.
- Исправлен NameError в build_device_manage_keyboard: ссылки на неопределённые connect_url/mobile_connect_url удалены из управления. Кнопка Mobile помещена в build_happ_connect_keyboard, получающий соответствующие ссылки.
- Существующие callback_data, URL, CopyTextButton и WebAppInfo сохранены. Настройки меню Mini App, платежей и пилота не меняются.

## Проверка

На aiogram 3.29.1 проверены 24 варианта клавиатур: сериализация, одна кнопка на строку, тип действия, длина callback_data, стили, варианты Basic/Mobile и сохранение существующих команд/ссылок. Отдельно проверена сборка экрана помощи и компиляция изменённых модулей. Сетевые запросы в Telegram и backend не выполнялись.

## Установка

Распаковать архив в чистую рабочую копию. Проверить git diff --check. Собрать образ bot и выполнить импорт клавиатур командой Python в одноразовом контейнере. После коммита, push и pull на сервере обновить только сервис bot:

```bash
docker compose up -d --no-deps --build bot
docker compose logs --tail=50 bot
```

Открыть /start либо вернуться на главную в боте. Уже отправленные старые клавиатуры обновятся при повторном открытии экрана. Проверить главную, подписку, инструкцию, управление устройством и экран подтверждения отключения (само отключение выполнять только при необходимости).

Стили primary/danger предусмотрены Telegram Bot API; отображение цвета зависит от клиента Telegram.
