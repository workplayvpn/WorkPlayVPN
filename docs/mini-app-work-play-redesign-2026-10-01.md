# Work&PlayVPN: новый Mini App

База обновления: исходники коммита 33f7ba2. Архив меняет только три файла Mini App и добавляет этот документ. Миграции базы данных и изменения переменных окружения не требуются.

## Изменения

- Графитовая палитра с бирюзовыми акцентами и янтарным разделом рефералов; светлая тема Telegram сохранена.
- Главная, Каталог, Подписки, Рефералы в нижней навигации. Профиль открывается кнопкой в шапке.
- Карточки Basic и Mobile показывают отдельные сроки из API и открывают управление выбранной подпиской.
- Подключение существующего устройства выбирает персональную ссылку нужной подписки. Для Mobile вне автоматического пилота сохранена прежняя ссылка.
- После добавления устройства из карточки Mobile открывается mobile_connect_url, когда он доступен.
- Устройства и их лимит остаются общими: счётчик использует active_count / total_limit, включая дополнительные места, предоставленные backend.
- Каталог показывает только доступные пользователю версии и реальные цены. Пилотные настройки не расширяются.
- Реферальный раздел сообщает о будущем запуске. Начислений, персональных ссылок и выплат пока нет.
- Сохранены подтверждение удаления устройства, смена региона с флагами, пробный доступ, платежи и закрытие истёкшего сеанса Telegram.
- Новые ресурсы имеют версию 20261001-1 для обновления кэша.

## Проверки

Проверен синтаксис JavaScript и выполнены проверки DOM на сценариях без подписки, Basic + Mobile, только Mobile, прежней схемы подписки, заполненного лимита, раздельного выбора ссылок, навигации и безопасного отображения текста. В HTML нет inline-обработчиков и inline-скриптов, запрещённых текущим CSP.

Визуальная проверка в Telegram/iOS и проверка реальных подключений требуют проверки после развёртывания. Полный набор backend-тестов необходимо запустить локально штатной командой проекта.

## Локальная проверка

В чистой рабочей копии распаковать архив в корень проекта. Затем:

```powershell
git -c core.whitespace=cr-at-eol diff --check
docker compose --profile testing run --rm tests
git diff --stat
```

После проверки на сервере открыть Mini App заново. Проверить тёмную/светлую тему, навигацию, сроки обеих подписок, подключение каждого типа и устройства, выбор срока продления, текущий регион, подтверждение удаления, лимит и выход после истечения сеанса.

Покупка дополнительных мест, реферальная программа, QR-коды и отчёты о проблемах — отдельные следующие задачи; новых имитационных кнопок для них не добавлено.
