# Regions and Mini App device cards

- Supported regions: Netherlands (NL), Germany (DE), Russia (RU), Finland (FI).
- The Mini App shows the corresponding flag in the region card and selector.
- Turkey (TR) is retired by Alembic revision `8e7a1c4b902d`. It and any associated node are inactive. Existing records remain so foreign keys and historical data stay intact. All region catalogs and device assignment paths already require `is_active`.
- Device names use the card's full top row at a smaller responsive font size. The public ID and delete action occupy the next row.
- After deployment, run `alembic upgrade head` before exposing the updated UI; refresh Mini App through the bot to load the cache-busted assets.
