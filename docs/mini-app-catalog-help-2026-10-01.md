# Каталог и переход в бот: доработка Mini App

База: f0cba4c. Только frontend: миграций и изменений настроек пилота нет.

- Каталог содержит описания Basic и Mobile, списки возможностей, сравнение и кнопки перехода к активной подписке. Цены и сроки перенесены на отдельный экран, открываемый кнопкой выбора Basic или Mobile.
- Продление активной подписки открывает сроки выбранной версии. Назад из выбора срока ведёт в каталог, из управления подпиской — к подпискам.
- В каталоге нет цен. На экране сроков цены и доступность по-прежнему берутся из backend.
- Mobile не появляется для пользователя, которому эта версия недоступна. Текст автоматического выбора маршрута отображается при наличии автоматических ссылок; прежний вариант описывает выбор профиля в Happ.
- Ссылки на Telegram из главной, профиля, рефералов и экрана ошибки открываются через WebApp.openTelegramLink. После успешного вызова Mini App закрывается, чтобы показать чат. При отсутствии API или исключении сохранён переход по обычному URL. Ссылка ведёт в существующий workplayvpn_bot.
- У Basic спокойный фон с орбитами. У Mobile ярче бирюзовое свечение и янтарный акцент. Фоны выполнены в CSS и не требуют дополнительных изображений.
- Версия ресурсов: 20261001-2.

## Проверено

Синтаксис JavaScript; DOM-сценарии предыдущей версии; отдельный выбор срока; отсутствие цен в каталоге; выбор правильной версии для продления; переход к активной подписке; ограничения пилота; сравнение; вызов Telegram API и запасной вариант перехода. В Chromium проверены экраны шириной 320, 393, 540 и 1000 px: нет горизонтального переполнения и ошибок JavaScript. Просмотрены скриншоты каталога, подписок и сроков, а также светлая тема.

Вызов Telegram проверен со stub API; реальный переход в Telegram iOS необходимо проверить после установки. Backend-тесты запускаются локально штатной командой проекта.

## Локальная проверка

```powershell
git status --short --untracked-files=no
# Если рабочая копия чистая:
Expand-Archive .\WorkPlayVPN-catalog-help-cards-2026-10-01.zip -DestinationPath . -Force
git -c core.whitespace=cr-at-eol diff --check
docker compose --profile testing run --rm tests
git diff --stat
```

После установки проверить: главная → помощь; каталог → описание и сравнение → выбор срока Basic/Mobile → назад; моя подписка → продление; обе темы Telegram. Вызов перехода в бот не отправляет сообщений пользователю от его имени.
