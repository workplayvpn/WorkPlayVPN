# Кнопка возврата из инструкции подключения

Добавлена видимая кнопка «← Назад» над инструкцией HAPP для всех платформ и Basic/Mobile. Она использует общий обработчик со встроенной кнопкой Telegram: возвращает на предыдущую страницу, а при прямом запуске в Telegram закрывает инструкцию. При прямом открытии в браузере без истории открывает /app/.

Обновлены версии CSS/JS для сброса кеша. Миграций и изменений настроек нет.

## Проверка

На компьютере запустить обычные backend-тесты с монтированием backend и ops. На сервере после коммита:

```bash
cd /opt/workplayvpn
git pull --ff-only && docker compose build backend && docker compose up -d --no-deps backend
docker compose ps backend
```

Заново открыть Mini App → Basic/Mobile → Подключить через Happ. Нажать видимую кнопку «← Назад» и проверить возврат. Проверить встроенную кнопку Telegram. Для проверки не нужно импортировать подписку повторно.
