# Переименование подписки Mobile в Pro

Название Pro используется в Mini App, Telegram-боте, подарках, базе знаний,
метаданных подписки и названиях профилей Happ. Старые настроенные названия
профилей Happ преобразуются при выдаче ссылки.

Миграция c10509ab7e31 меняет только plans.name для access_tier=mobile.
Идентификаторы mobile_*, access_tier=mobile, API, ссылки, VPN-данные, цены,
сроки, лимиты и оплаченные подписки сохраняются. Предыдущие миграции не меняются.
Метки Happ `only Mobile` обозначают мобильную сеть и сохраняются.
Ранее созданные счета могут содержать прежнее название; новые получают Pro.
В Happ обновите подписку для получения нового названия.

## Установка на сервере

Сначала запустите install.py --check. Затем --apply, который сохраняет
резервные копии файлов и устанавливает только перечисленные в release.json файлы.
Установщик не запускает Docker и не обращается к базе данных.

После установки:

```bash
cd /opt/workplayvpn
docker compose build backend
docker compose run --rm --no-deps backend alembic upgrade head
docker compose up -d --no-deps backend
docker compose restart bot
docker compose ps backend bot
```

Если миграция завершилась ошибкой, не выполняйте следующие команды,
пришлите вывод. Caddy перезапускать не требуется: файлы Mini App смонтированы.
Не используйте --remove-orphans: существующий Xray нужен сервису.

## Сохранение в Git

review.patch содержит только это изменение. На ноутбуке в актуальном проекте:

```powershell
git apply --check "ПУТЬ-К-РАСПАКОВАННОМУ-АРХИВУ\review.patch"
git apply "ПУТЬ-К-РАСПАКОВАННОМУ-АРХИВУ\review.patch"
```

После проверки создайте отдельный коммит. Серверные изменения Compose/Caddy
в этот коммит добавлять не следует.
