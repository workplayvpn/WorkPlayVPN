# Вход в центр помощи внутри Telegram Web

Mini App больше не зависит от поддержки cookie во встроенном окне. После проверки персонального ключа сервер возвращает подписанную сессию помощи сроком на один час. Она хранится только в памяти окна и отправляется в X-Help-Session только на /mini-app/support/. Каждое обращение сервер сверяет с подтверждённым Telegram-аккаунтом. При выходе или блокировке интерфейса значение удаляется из памяти. Ключ и сессия не записываются в localStorage/sessionStorage или URL.

Подпись сессии Mini App отделена от подписи cookie публичного сайта. Истёкшие, изменённые, чужие сессии и сессии после смены версии ключа отклоняются. Существующий вход по cookie остаётся совместимым. Для публичного сайта поведение не изменено.

Миграций нет. На сервере после коммита обновить backend; frontend Caddy читает из смонтированной папки. Версии JS обновлены в index.html. Закрыть и заново открыть Mini App, проверить ввод ключа, статьи, историю обращений, выход и повторный запрос ключа. Обращение создавать только при необходимости.

Проверено локально: 15 серверных тестов доступа; сценарий входа без cookies, ограничения заголовка областью помощи и выхода в JavaScript. Полный backend-набор запускается пользователем в Docker.
